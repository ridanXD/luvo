# LUVO — Laundry Finder

Aplikasi mobile untuk mencari, membandingkan, dan memesan layanan laundry dari berbagai mitra dalam satu platform.

Repository: [ridanXD/luvo](https://github.com/ridanXD/luvo)

## Fitur Utama

- **Laundry Finder** — Mencari dan menemukan laundry berdasarkan nama atau area.
- **Pencarian dan Filter** — Menyaring laundry berdasarkan lokasi, jenis layanan, dan kisaran harga.
- **Detail Laundry** — Melihat informasi mitra, layanan, harga, jam operasional, dan lokasi.
- **Google Maps Integration** — Menampilkan lokasi laundry pada peta.
- **Pemesanan Laundry** — Membuat pesanan dengan memilih layanan dan menambahkan catatan.
- **Manajemen Pesanan** — Mitra dapat menerima atau menolak pesanan serta memperbarui status pengerjaan.
- **Order Tracking** — Memantau status pesanan dan melihat riwayat pemesanan.
- **Notifikasi** — Mendapatkan pemberitahuan terkait konfirmasi dan perubahan status pesanan.
- **Role-based Access** — Memisahkan akses pelanggan dan mitra laundry.
- **Camera & File Upload** — Mendukung pengambilan dan pemilihan foto untuk dokumentasi pesanan.

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **API:** REST API
- **Maps:** Google Maps
